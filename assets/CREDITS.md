# Asset credits

Every file in `assets/` comes from [Poly Haven](https://polyhaven.com) and is in the public domain under the
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) dedication: free to use, change and redistribute
for any purpose, with no attribution required. They are listed here anyway, with thanks.

They were fetched on 2026-11-24, at Poly Haven's 1k size. The folder holds data only: JPEG images, and for each
model a `.gltf` text file that describes its shape and a `.bin` file of numbers. No code was fetched; the few
lines that read these files are the game's own (`js/assets.js`). About 41 MB in all.

Each asset's page is at `https://polyhaven.com/a/<asset>`, which names its authors.

## Models (`assets/models/<asset>/`)

Each folder holds `<asset>.gltf`, `<asset>.bin` and a `textures/` folder with the model's colour and normal
pictures (and an alpha picture for the plants).

| Used for | Poly Haven asset |
| --- | --- |
| Barrels | `wine_barrel_01` |
| Crates | `wooden_crate_01` |
| Tables | `WoodenTable_01` |
| Boulders | `rock_07`, `rock_09` |
| Ferns under the trees | `fern_02` |
| Clumps of grass | `grass_medium_02` |

The game changes some of these when it loads them: the boulders and the crate have most of their colour taken
out, and everything is darkened to suit the place.

Everything else the game draws (people, beasts, buildings, fir trees, the sky, and most props) is generated by
the game's own code. If any file here is missing the game still runs, drawing that thing for itself.
